# 项目

## 项目一描述

一个工业 PLC 编程的 梯形图（LD）和功能块图（FBD）图形化编辑工具 ，用于以拖拽方式替代传统文本化的 PLC 编程。

### 技术栈

Vue 2 (^2.6.14) + Vuex 3 + Composition API

AntV X6 (^2.9.4) — 核心画布引擎

Element UI 2

webpack

### 项目结构

ldfbd/
├── src/
│   ├── index.js          # 组件库入口（Vue 插件）
│   ├── ld.js             # 梯形图模式入口
│   ├── fbd.js            # 功能块图模式入口
│   ├── src/
│   │   ├── LD.vue / FBD.vue   # 两种模式的容器组件
│   │   ├── ladderArea.vue     # ⭐ 核心编辑画布（213KB+，核心组件）
│   │   ├── components/        # 子组件（工具栏、功能块节点、变量管理等）
│   │   ├── store/modules/     # Vuex 状态（主要管理 cells 数据）
│   │   ├── utils/             # 工具函数（20+ 个文件：坐标、连线、删除、撤销等）
│   │   ├── dataJson/          # 功能块元数据 JSON（按 LD/FBD 分类，各 11 类）
│   │   └── api/ld.js          # 后端 API 接口
│   ├── assets/
│   │   ├── images/            # 梯形图元件图片（触点、线圈、定时器等）
│   │   └── svg/               # 图标
│   └── index.html
├── webpack.config.js     # Webpack 构建配置（UMD 库打包）
└── vue.config.js         # Vue CLI 后备配置

### 核心功能

1. 梯形图（LD）编辑 — 拖拽触点、线圈、功能块到画布，图形化编写 PLC 逻辑
2. 功能块图（FBD）编辑 — 使用功能块节点进行图形化编程
3. 编辑交互 — 撤销/重做、缩放、全屏、导入/导出、添加节/行
4. 变量管理 — 全局/局部变量的选择、新建、列表查看
5. 后端集成 — 通过 REST API（端口 9999）实现加载、保存、编译、运行监控

#### 数据流

- 状态管理 ：Vuex 统一管理 graphData （cells 数据）
- 核心画布 ： ladderArea.vue 初始化 AntV X6 画布，集成拖拽（DnD）、选择、历史、键盘等插件
- 功能块定义 ： dataJson/ 下按分类存放 JSON 格式的功能块元数据

#### 构建

- 输出为 UMD 库 （library name: Modal ），每个入口独立打包
- 开发服务器端口 9527 ，支持热重载
- 当前 webpack.config.js 只打包 ld 入口， fbd 入口被注释

## 项目二描述

这是一套工业控制器 Web 组态工具——Vue 3 可视化拖拽配置工业协议设备，REST API 下发到控制器固件，并集成 VSCode Web IDE 实现完整的组态-编程-调试工作流。

### 技术栈2

- Vue 3.4 + TypeScript + Vite 4
- Element Plus UI 库 + Pinia （持久化）+ Vue Router 4（动态路由）
- ECharts 5（仪表盘）、CodeMirror 6（脚本编辑）、vue-i18n（中英文）
- Axios 类封装（全屏 loading、401/403 拦截、错误处理）
- RSA 加密登录（jsencrypt）

## 项目三描述

为 code-server（Web 版 VSCode）定制的 IEC 61131-3 结构化文本（ST）语言 + LD 梯形图 PLC 编程插件 ，是 eCON 逻辑编程 IDE（fcs-ide，嵌入 9888 端口）的核心扩展。

基于微软官方 LSP 示例（lsp-sample）和 Custom Editor 示例（catScratch）二次开发。
